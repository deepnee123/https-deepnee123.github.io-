# Engineering portfolio

**Preview locally:** open `index.html` in a browser.

**Publish on GitHub Pages:** create a repo, upload everything in this folder, then
Settings > Pages > Deploy from a branch > `main` / root. Your site appears at
`https://your-username.github.io/repo-name/`. Naming the repo `your-username.github.io` gives a shorter link.

**Edit:** nearly everything is in `js/config.js` (text, theme, backgrounds, projects, media).
Colors are in `css/style.css` (top of the file). Put images and videos in `images/`
(for example `images/rover/cad.jpg`). Keep videos under about 50 MB, or use a YouTube ID.
